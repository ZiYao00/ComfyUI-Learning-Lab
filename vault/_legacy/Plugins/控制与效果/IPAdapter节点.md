权重类型参数说明：

![[Pasted image 20240718092731.png]]

|                        |                           |
| ---------------------- | ------------------------- |
| linear                 | 过渡和变化是直接且均匀的，没有加速或减速      |
| ease-in                | 缓入效果                      |
| ease-out               | 缓出效果                      |
| ease in-out            | 开始和结束时都有缓入缓出的效果           |
| reverse in-out         | 反向缓入缓出效果，即开始和结束部分是相反的缓入缓出 |
| weak input             | 指输入效果较弱，影响较小              |
| weak output            | 指输出的效果较弱，影响较小             |
| weak middle            | 中间部分的效果较弱                 |
| strong middle          | 指动画中间部分的效果较强              |
| style transfer         | 风格迁移                      |
| composition            | 构图迁移                      |
| strong style transfer  | 强烈风格迁移                    |
| style and composition  | 风格和构图迁移                   |
| style transfer precise | 精确风格迁移                    |
| composition precise    | 精确构图迁移                    |
