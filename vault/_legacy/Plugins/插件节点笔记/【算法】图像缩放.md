#图像缩放算法
### 放大方法/缩放插值方法

![[Pasted image 20240829212940.png]]

| 英文名称                           | 中文名称      | 简写         | 效果排序 |
| ------------------------------ | --------- | ---------- | ---- |
| Lanczos Interpolation          | Lanczos插值 | Lanczos    | 1    |
| Bicubic Interpolation          | 双三次插值     | Bicubic    | 2    |
| Bilinear Interpolation         | 双线性插值     | Bilinear   | 3    |
| Area Interpolation             | 区域插值      | Area       | 4    |
| Nearest Neighbor Interpolation | 最近邻插值     | Nearest-NN | 5    |
| Bilinear Interpolation         | 双线性插值     | Bislerp    | 6    |

- 效果最好的是[Lanczos插值]，它在保持图像清晰度和抑制混叠现象方面表现优异。
- 其次是[Bicubic双三次插值]，它使用周围16个像素值的双线性关系以及像素变化率来计算采样点的灰度值，能够产生平滑的边缘并且图像质量损失较少。
- [Bilinear双线性插值]效果居中，它通过对周围像素进行加权平均来计算目标像素的值，可以有效减少图像的锯齿和模糊，但可能导致一些细节丢失。
- [Area区域插值]在图像抽取时能提供较好的效果，但在放大图像时，效果可能类似于最近邻插值法。
- 效果最差的是[Nearest-exact最邻近插值]算法，它未考虑周围像素点的影响，采样后的灰度值有明显的不连续性，图像质量损失较大，会产生马赛克或者锯齿现象。

### 缩放模式、缩放条件

![[Pasted image 20240901214127.png]]

| 缩放方法            |       | 效果/作用                                                   |
| --------------- | ----- | ------------------------------------------------------- |
| Strech          | 拉伸    | 将原有图片拉伸放大方法                                             |
| Keep proportion | 保存比例  | 将图片保存原有比例放大，注意放大的图片是按照设置的最小边长进行比例放大的，所以会出现与设置输出宽高不一样的情况 |
| Fill/crop       | 填充或裁剪 | 将图片进行裁剪或填充放大，裁剪是中心裁剪，这里填充是指的原图画面部分填充                    |
| Pad<br>         | 填充黑色  | 将图片进行填充放大，在保持放大后图片的原图区域部分具有原图比例外对其余部分进行黑色像素填充           |

| 条件                  | 中文名称    | 功能作用描述                                 |
| ------------------- | ------- | -------------------------------------- |
| always              | 总是      | 无论图像的原始尺寸如何，总是执行指定的操作。                 |
| downscale if bigger | 降采样（缩小） | 如果目标尺寸比原始图像大，则执行降采样（缩小）操作。             |
| upscale if smaller  | 升采样（放大） | 如果目标尺寸比原始图像小，则执行升采样（放大）操作。             |
| if bigger area      | 如果面积更大  | 用于判断目标图像的面积是否比原始图像的面积大，如果是，则可能执行降采样操作。 |
| if smaller area     | 如果面积更小  | 用于判断目标图像的面积是否比原始图像的面积小，如果是，则可能执行升采样操作。 |

| 缩放插值                  | 优点                                                                                 | 缺点                                                    | 说明                                                            |
| --------------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------- |
| nearest-exact<br>最近邻  | 1. 计算速度快，算法简单<br>2. 保留原始图像的硬边缘特征，适合像素艺术和图标的缩放<br>3. 不会引入新的颜色（插值产生的新像素仅从原始像素中选取）    | 1. 缩放后的图像可能会显得粗糙、不平滑，尤其是在大幅放大时<br>2. 细节保留较差，容易产生锯齿效应  | 用最接近的像素点进行缩放，适用于需要精确像素对齐的场景，但可能会导致图像质量下降                      |
| Bilinear<br>双线性       | 1. 计算速度较快，比最近邻插值更平滑<br>2. 保留一定的图像细节，适用于简单的图像缩放<br>3. 适合处理一般的图像缩放场合                 | 1. 细节保留不如Lanczos和Bicubic<br>2. 对于高对比度图像，可能会产生模糊和轻微的失真 | 通过考虑像素点及其四个最近邻点来计算新像素的值。它比最近邻插值平滑，但可能在边缘处产生模糊                 |
| Bicubic<br>双三次<br>双立方 | 1. 通常比双线性插值提供更好的图像质量，尤其是在保留细节方面<br>2. 平滑度较好，适合处理高质量图像<br>3. 在大部分情况下，能够在速度与质量之间达到平衡 | 1. 计算复杂度比双线性插值高，速度略慢<br>2. 可能会产生轻微的模糊，特别是在处理低分辨率图像时   | 比双线性更好的图像质量，它考虑了像素点及其16个最近邻点。这种方法通常会产生更平滑的图像，但计算量更大           |
| Bislerp<br>双球面线性      |                                                                                    |                                                       | 双线性插值的扩展，它使用双线性插值来插值双线性插值的结果，从而在缩放时提供更平滑的过渡                   |
| Area<br>区域            | 1. 对于图像缩小时效果良好，可以有效地减少别名效应(aliasing)<br>2. 平滑度适中，通常不会产生明显的伪影                       | 1. 在放大时，图像可能会显得有些模糊<br>2. 较其他插值方法，计算速度略慢              | 一种基于像素覆盖区域的方法，它考虑了原始图像中每个像素对新像素的贡献。这种方法在缩放时可以提供较好的图像质量，但计算量较大 |
| Lanczos<br>兰索斯        | 1. 质量高，能很好地保留图像的细节<br>2. 对于锐化效果明显的图像处理非常合适<br>3. 适合于需要高保真度和最小化失真的场合                | 1. 计算复杂度较高，速度较慢<br>2. 对于某些图像可能会产生振铃效应（即边缘出现不自然的晕圈）    | 一种使用正弦型窗口的插值方法，它在缩放时可以提供非常高质量的图像，但计算量是所有方法中最大的                |
