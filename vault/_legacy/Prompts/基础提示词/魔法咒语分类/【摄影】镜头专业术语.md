| 术语                          | 描述                        | 适用镜头类型                                    |
|-----------------------------|---------------------------|-------------------------------------------|
| 微距摄影（Macro Photography）     | 拍摄非常近距离的物体，如昆虫、花朵等        | 微距镜头（Macro Lens）                          |
| 特写（Close-up）                | 拍摄距离较近，展示物体的局部细节          | 特写镜头（Close-up Lens）或特写滤镜（Close-up Filter） |
| 近景（Medium Shot）             | 拍摄距离适中，展示人物上半身或小范围场景      | 标准镜头（Standard Lens）                       |
| 远景（Long Shot）               | 拍摄距离较远，展示人物全身或较大范围场景      | 长焦镜头（Telephoto Lens）                      |
| 广角（Wide-Angle）              | 捕捉比标准镜头更宽广的视野，适合风景和建筑摄影   | 广角镜头（Wide-Angle Lens）                     |
| 标准镜头（Standard Lens）         | 提供接近人眼所见的视角，适合日常拍摄        | 标准镜头（Standard Lens）                       |
| 长焦镜头（Telephoto Lens）        | 放大远处的物体，适合拍摄远处的景物或动物      | 长焦镜头（Telephoto Lens）                      |
| 超远摄镜头（Super Telephoto Lens） | 拍摄非常远的物体，常用于体育摄影和野生动物摄影   | 超远摄镜头（Super Telephoto Lens）               |
| 鱼眼镜头（Fisheye Lens）          | 捕捉极端广角视角，产生独特的弯曲效果        | 鱼眼镜头（Fisheye Lens）                        |
| 移轴镜头（Tilt-Shift Lens）       | 调整焦平面和视角，减少透视失真，常用于建筑摄影   | 移轴镜头（Tilt-Shift Lens）                     |
| 变焦镜头（Zoom Lens）             | 可以在一定范围内调整焦距，提供多种拍摄距离的灵活性 | 变焦镜头（Zoom Lens）                           |
| 定焦镜头（Prime Lens）            | 焦距固定，通常提供更好的光学性能和更大的光圈    | 定焦镜头（Prime Lens）                          |
