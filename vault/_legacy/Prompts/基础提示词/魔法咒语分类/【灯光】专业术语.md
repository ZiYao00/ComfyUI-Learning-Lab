

|                                                         |                                      |
| ------------------------------------------------------- | ------------------------------------ |
| Backlighting、Backlit<br>背光或逆光                           | 光线从主体的背面照射过来，通常用于创造剪影效果或突出主体的轮廓      |
| Front Lighting、Frontlit<br>正面光                          | 光线直接照射在主体的前面，可以减少阴影，使细节更加清晰          |
| Side Lighting、Sidelit<br>侧面光                            | 光线从一侧照射，能够产生明显的阴影和立体感                |
| Three-Quarter Lighting、Rembrandt Lighting<br>三分之四光或伦勃朗光 | 光线从主体的一侧上方照射，常用于肖像摄影，能够产生丰富的光影效。     |
| Butterfly Lighting、Paramount Lighting<br>蝴蝶光或派拉蒙光       | 一种特殊的侧面光，光线从上方45度角照射，使主体的面部产生蝴蝶形状的阴影 |
| high-Key Lighting<br>高调光                                | 使用大量光线，创造明亮和乐观的氛围                    |
| low-Key Lighting<br>低调光                                 | 使用较少的光线，创造神秘或戏剧性的氛围                  |
| Natural Lighting<br>自然光                                 | 利用太阳或其他自然光源的光线                       |
| Artificial Lighting<br>人造光                              | 使用人造光源，如灯具或闪光灯                       |
| Fill Light<br>补光                                        | 用来减少主体上的强光和阴影，使画面更加柔和                |
| Key Light<br>主光                                         | 是场景中的主要光源，用于定义主体和场景的主要照明             |
| Rim Light<br>边缘光                                        | 从背后照射并在主体的边缘形成光晕，用来突出主体              |
| Global Illumination<br>全局光                              | 模拟光线在环境中的散射和反射，常用于3D渲染和视觉效果          |
| Ambient Light<br>环境光                                    | 场景中均匀分布的光线，通常与其他类型的光线结合使用            |
| Diffuse Light<br>散射光                                    | 光线经过散射后变得柔和，常用于减少阴影的硬度               |
| Direct Light<br>直射光                                     | 直接照射在主体上，产生清晰的阴影                     |
| Soft Light<br>软光                                        | 光线柔和，阴影边缘模糊，常用于肖像摄影                  |
| Hard Light<br>硬光                                        | 光线直接且强烈，产生清晰且边缘锐利的阴影                 |
