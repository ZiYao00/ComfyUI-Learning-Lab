# 旧资料整理说明

`_legacy/` 用来暂存历史 ComfyUI 笔记。

这些内容来自旧的 `comfyui.backup`，目前只根据 **目录名 / 文件名** 做了第一轮分类，没有系统校验正文内容，也不代表已经符合 ComfyUI Learning Lab 的正式文档规范。

## 当前分类

```text
_legacy/
├── Foundations/   # 安装、报错、尺寸等基础内容
├── Models/        # 模型基础与模型笔记
├── Plugins/       # 插件与节点相关
├── Prompts/       # 提示词、Tags、公式
├── Resources/     # 资源、GitHub、素材入口
├── Services/      # API / 服务端平台
├── Tips/          # 小技巧
├── Training/      # LoRA 等训练内容
├── Tutorials/     # 待消化教程
└── Video/         # 视频模型、视频插件、视频工作流相关
```

## 迁移原则

旧资料不会直接复制到正式知识区。

每次只处理一个明确主题：

1. 先判断旧内容是否仍有价值。
2. 对照当前官方资料或实际工作流重新验证。
3. 删除过期、重复、纯收藏型信息。
4. 改写成当前项目的“说明书式”学习文档。
5. 迁入正式目录，例如 `Models/`、未来的 `Plugins/`、`Workflows/` 等。
6. 更新 `docs/TASKS.md` 的迁移进度。

## 不在本轮整理范围

`vault/知识星球.backup/` 是外部备份资料：

- 保持原样。
- 不参与当前目录迁移。
- 已加入 `.gitignore`，不会提交到 Git 仓库。

## 当前优先级

优先迁移和当前实际学习最相关的内容，不按旧资料数量顺序处理。

建议优先关注：

- H3 实战后暴露出来的基础知识缺口。
- 视频模型相关旧笔记（Wan / Hunyuan / LTX 等）。
- 常用插件和节点。
- 安装、报错与模型路径等高复用基础内容。
