# [B部分：解压文件到指定目录]
  
1、把exiftool-12.81里的exiftool.exe，放到 C:\Windows 路径下
[Exiftool官网](https://exiftool.org/)

2、解压[Ebsynth](https://ebsynth.com/)到任意路径
例：D:\Program Files\EbSynth

3、解压[FFmpeg](https://ffmpeg.org/)到任意路径，*后续需要添加环境变量
例：C:\Program Files\ffmpeg

4、解压[插件模型文件]到最高权限的用户名目录下，列：`C:\Users\YAO`
	文件说明
	.ifnude           `Roop换脸插件模型`
	.insightface    `Roop换脸插件模型`
	[.transparent-background]    `抠图插件模型`
		手动安装 [transparent-background] 方法，进入到整合包的python目录下，
		右键打开[命令提示符]，输入  python.exe -m pip intsall transparent-background（全程打开魔法）

# [C部分： 添加插件到系统的环境变量 ]

![[Pasted image 20240905165502.png]]

1、添加 [ 整合包的python路径 ] 到系统的 [ 环境变量 ] 下的 [ 用户变量 ] 
将根目录下的【python路径】及python里的【Scripts路径】，添加到 [ 用户变量的【Path 】] 里
例：`G:\AIGC\SD-WebUI-aki\python` 及 `G:\AIGC\SD-WebUI-aki\python\Scripts`

---
2、添加 [FFmpeg](https://ffmpeg.org/) 到系统的环境变量下的 [ 用户变量 ] 
例：`C:\Program Files\ffmpeg\bin` ，并将路径添加到 [ 用户变量的【Path 】] 里

查看是否成功，打开cmd，输入ffmpeg -version

制作bat添加到环境变量→

```
使用Windows PowerShell（管理员）添加到系统环境变量

$Path = [System.Environment]::GetEnvironmentVariable('Path', 'User') $NewPath = $Path + ';G:\AIGC\ComfyUI\.ext\python.exe' [System.Environment]::SetEnvironmentVariable('Path', $NewPath, 'User')

```
