
**1、[手动命令行]安装方式，新手不推荐**

[ 安装requirements.txt所有的依赖 ]

```
G:\AIGC\ComfyUI_Mie_V6\python_embeded\python.exe -m pip install -r requirements.txt

```

[ 安装指定依赖 ]

```
.\python.exe -m pip install transparent-background
.\python.exe -m pip install "websockets>=13,<15.1"
.\python.exe -m pip install "aiofiles~=24.1"
```

[ 强制安装到指定环境 ]

```
# 在python解释器的当前目录下，打开cmd，输入以下命令

G:\AIGC\ComfyUI\.ext\python.exe -m pip install x
G:\AIGC\ComfyUI_Mie_V6\python_embeded\python.exe -m pip install x

```
