### 以下举例如何安装 [ natten ] 库


- 使用 [ CMD命令提示符 ]或[ PowerShell ]，导航到虚拟环境的Scripts目录
- 输入 [ activate ] 命令激活虚拟环境


```
对于[CMD]
cd /d G:\AIGC\ComfyUI\.ext\Scripts

对于[PowerShell]
cd G:\AIGC\ComfyUI\.ext\Scripts

输入
activate 
```

`activate激活后，您应该在命令行提示符前看到虚拟环境的名称，这表明虚拟环境已经成功激活。`

`使用`/d`参数在CMD中可以确保即使当前盘符不同，也能正确改变到目标目录`

---

#假如文件在Scripts根目录下
